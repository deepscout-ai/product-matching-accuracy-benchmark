# Labelling rules

Written before we looked at the results.

A pair is **correct** when both sides are the same sellable product: the same brand, model, generation,
colour or finish, and quantity.

- **Colour or finish:** if both sides name a colour and they differ, the pair is wrong. If one side names
  no colour (for example, one page for all colours), the pair isn't counted wrong for colour.
- **Bundles:** a bundle and a single item, or two bundles with different contents, are different products.
- **Quantity:** a pair of speakers and a single speaker are different products.
- **Generation:** different versions (Mk2 vs Mk3, 2024 vs 2025 model) are different products.
- **Unclear:** when the product data isn't enough, we checked the live product page.

Pairs are grouped by EAN: **same EAN** on both stores, **different EANs**, and **no EAN on one store**. This
repo publishes the last two groups: the matches a plain EAN lookup can't make.
